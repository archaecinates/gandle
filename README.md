# Gandle

Custom Doodle Keychain Shop
Gandle adalah website pemesanan custom doodle keychain yang memungkinkan pelanggan memilih paket, mengunggah foto referensi, menambahkan catatan pesanan, dan melakukan checkout secara online

Features
- Pilihan paket doodle keychain
- Catatan khusus untuk setiap paket
- Upload beberapa foto referensi untuk setiap paket
- Pembayaran Cash atau QRIS
- Upload bukti pembayaran untuk QRIS
- Order tersimpan secara otomatis

Tech Stack
- HTML
- CSS
- JavaScript
- JSON
- Google Apps Script
- Google Sheets
- Google Drive
- Vercel
